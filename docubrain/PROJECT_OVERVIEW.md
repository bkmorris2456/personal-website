# Project overview

**Verified.** This personal software development portfolio presents the owner's background, experience, skills, and projects. Visitors browse the homepage, follow available project links, and can submit a contact message. The owner is the intended dashboard operator and can use its forms to manage positions, projects, and skills where Firestore permissions allow.

The site uses React, Vite, Material UI, React Router, Firebase Auth and Firestore, and EmailJS. GitHub Pages is the configured hosting target. Project scope is the personal showcase, contact form, and content management UI. The repository implements a browser application with managed services.
