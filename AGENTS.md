# Repository instructions

## DocuBrain

Before substantive work, read [project memory](docubrain/MEMORY.md) and [current state](docubrain/CURRENT_STATE.md), then review the latest relevant [session](docubrain/sessions/SESSION_INDEX.md). Consult relevant architecture, feature, and decision records before changing related code. Recheck stale claims against source and verified test results, which take precedence.

At the end of substantive work, update affected documentation, record significant decisions and development outcomes, and add and index a session record covering changes, validation, unresolved work, and next steps. Refresh memory and current state when project context changes. Follow the [DocuBrain conventions](docubrain/README.md) and keep updates proportional to the work.
